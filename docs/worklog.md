## 2026-11-05 23:55 M1 物理核心完成
- 目标：零件目录、构造 API、编译器、任务与仿真、证书 C0 到 C3、夹具与元评测。
- 做了什么：
  - `mlab/catalog`：材料、关节、弹簧、电机目录；`theta_world` 先验（max/min 比不超过 10）及采样。
  - `mlab/construct`：IR、逐步校验（支撑、穿透、销钉位置、固定件接触、密度、目录型号、范围）、自然语言描述、编译器。编译器中每个零件对应一个刚体，关节零件只排除与其销钉所在零件的碰撞。
  - `mlab/sim`：仿真运行器，负责 setup 坐标、携带物随动、闩锁、阶段控制、落点/终态/最高点/关节角四类结果量，以及能量记录；另有带噪观测和特征向量。
  - `mlab/referee`：通用 oracle（Sobol 表 + Nelder-Mead）、证书 C0 到 C3（Wilson 区间三档判定）、灰盒参考学习者（粗搜索 + Nelder-Mead）。
  - `fixtures/devices`：两台合格夹具（摆锤击块、弹簧发射钢球），6 个构造期作弊，4 个证书期作弊。
- 实测发现并处理的问题（详见 D-011）：
  1. 摆锤夹具的目标区间对“轻锤头、高摩擦”的先验角点不可达，被 C1 正确拦下；已把目标区间缩到全先验可达的范围。
  2. 拉角大于 1.5 rad 时物块被打下桌沿，结果混沌，误差约 0.5 m。步长收敛检查因此改为只在命中解上做。
  3. 软接触碰撞的一阶步长误差在 1 到 3 cm。基础步长改为 0.001 s；收敛阈值改为 1 倍容差。
  4. 某个世界的真实物性接近先验中心，导致名义参数成功率达到 0.96。C2 改为在先验上评估。
  5. 灰盒参考学习者原来用 least_squares，命中 2/8；改为粗搜索 + Nelder-Mead 后命中 8/8。
  6. 弹簧发射台最初几乎打不出物块，原因有二：活塞在端部止挡附近才撞到物块；软接触需要约 20 ms 才能传递动量。修正为加长行程、改用钢制活塞和钢球、抬高台面。
  7. MuJoCo 的父子刚体碰撞过滤对“焊接到世界的父体”不生效，导致销钉被判为穿模。修正为关闭全局过滤，对每个关节零件只排除它与销钉所在零件之间的碰撞。

  - FULL 认证（world seed 7、8）：两台合格夹具全部 CERTIFIED；发射台约 12 s，摆锤约 77 s（约 3.5k 次仿真）。
  - 作弊夹具的失败关卡：不可达目标在 C1 失败；容差过大在 C2（名义参数）失败；隐藏量无关的转台在 C2（名义参数）失败；桌沿外的混沌目标在 C1 失败。

## 2026-11-06 00:50 M2 裁判协议与离线闭环完成
- 做了什么：
  - `mlab/referee`：
    - `session.py`：协议状态机。阶段依次为前测、实验室、提交理论、考试、反馈。规则：实验必须先预测；第 10、20、30 次实验由裁判指定；前测和考试结果在会话结束后才公布，且公布的是带噪观测值；预算强制执行。
    - `manual.py`：说明书由构造记录自动生成。
    - `leak.py`：扫描建造者文本中接近隐藏值的数字和禁用短语。
    - `channel.py`：哈希链信道日志。
    - `theory_eval.py`：在独立解释器中运行 `predict.py`，评测四类问题（分布内、外推、改装、互换）以及改装对结果的影响幅度。
    - `metrics.py`、`report.py`：失败标签与给建造者的指引。
    - `changelog.py`：版本之间的结构变更。
  - `mlab/agents`：
    - `lab_api.py`：LabAPI 协议与 LocalLab。
    - `learners/`：NaiveLearner；SurrogateLearner（高斯过程，主动学习，与装置无关）；ScriptedAgent（记忆与 fork）。
    - `builders/reference.py`：参照课程，只用于离线复现。
  - `mlab/orchestrator.py`、`mlab/cli/main.py`：`mlab run`、`mlab verify-log`。
- 实测发现并处理的问题：
  1. 统计功效不足（详见 D-012）：C2 只用 2 到 3 个先验实例时结果摆动很大。大样本估计显示，两台“合格夹具”的名义成功率约为 0.39 和 0.41，实际偏易。改进 C2 统计后，按敏感区重设了目标区间。
  2. 发射台没有装置专属的隐藏量，因此孪生实例完全相同，互换测试恒为 1.0。现在标记为“不具信息量”，并引导建造者加入装置专属隐藏量。孪生实例改为对偶采样。
  3. 脚本学习者的“负迁移”：把上一实例的原始数据混入本实例的模型，导致第 3 轮考试只有 12%（无记忆的对照组为 100%）。改为记忆只作为前测先验；原来的混合方式保留为消融选项 `memory_mode="pool"`。结论：跨轮记忆应保存可迁移的知识（世界物性、方法），而不是绑定于具体实例的数据。这一点要写进学习者 prompt 的工具说明里，以中性方式表述。
  4. 编辑模式安装时缺少 `.pth`：创建 venv 时 `mlab/` 还不存在。已用 `uv sync --reinstall-package mlab` 修复。
  5. 浮点边界问题：`0.3 - 0.255 < 0.045`。可改装量的比较已加上 1e-9 容差。

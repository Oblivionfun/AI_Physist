## 2026-11-05 23:55 M1 物理核心完成
- 目标：零件目录、构造 API、编译器、任务与仿真、证书 C0 到 C3、夹具与元评测。
- 做了什么：
  - `mlab/catalog`：材料、关节、弹簧、电机目录；`theta_world` 先验（max/min 比不超过 10）及采样。
  - `mlab/construct`：IR、逐步校验（支撑、穿透、销钉位置、固定件接触、密度、目录型号、范围）、自然语言描述、编译器。编译器中每个零件对应一个刚体，关节零件只排除与其销钉所在零件的碰撞。
  - `mlab/sim`：仿真运行器，负责 setup 坐标、携带物随动、闩锁、阶段控制、落点/终态/最高点/关节角四类结果量，以及能量记录；另有带噪观测和特征向量。
  - `mlab/referee`：通用 oracle（Sobol 表 + Nelder-Mead）、证书 C0 到 C3（Wilson 区间三档判定）、灰盒参考学习者（粗搜索 + Nelder-Mead）。
  - `fixtures/devices`：两台合格夹具（摆锤击块、弹簧发射钢球），6 个构造期作弊，4 个证书期作弊。
- 实测发现并处理的问题（详见 D-011）：
  1. 摆锤夹具的目标区间对“轻锤头、高摩擦”的先验角点不可达，被 C1 正确拦下；已把目标区间缩到全先验可达的范围。
  2. 拉角大于 1.5 rad 时物块被打下桌沿，结果混沌，误差约 0.5 m。步长收敛检查因此改为只在命中解上做。
  3. 软接触碰撞的一阶步长误差在 1 到 3 cm。基础步长改为 0.001 s；收敛阈值改为 1 倍容差。
  4. 某个世界的真实物性接近先验中心，导致名义参数成功率达到 0.96。C2 改为在先验上评估。
  5. 灰盒参考学习者原来用 least_squares，命中 2/8；改为粗搜索 + Nelder-Mead 后命中 8/8。
  6. 弹簧发射台最初几乎打不出物块，原因有二：活塞在端部止挡附近才撞到物块；软接触需要约 20 ms 才能传递动量。修正为加长行程、改用钢制活塞和钢球、抬高台面。
  7. MuJoCo 的父子刚体碰撞过滤对“焊接到世界的父体”不生效，导致销钉被判为穿模。修正为关闭全局过滤，对每个关节零件只排除它与销钉所在零件之间的碰撞。

  1. 规则顺序：宽泛的写放行（`~/.cursor`）写在禁令之后，覆盖了对旧会话和 `plans` 的禁读。改为分层渲染。
  2. 沙箱内的 Python 导入失败：可编辑安装的 `.pth` 指向被禁读的项目目录，导入机制扫描时抛出 PermissionError，而不是忽略。学习者和理论执行器改用独立的 venv（`~/.local/share/mlab/learner-venv`），里面不含 mlab；工作目录也必须设为自己的工作区。
  3. cursor-agent 的 shell 工具在执行前会逐级解析工作目录的符号链接，而祖先目录被禁读。改为对工作区的祖先链只放行 `file-read-metadata`（literal），不放行列目录和读内容。
  4. Node 启动时会 stat 标准输入输出；若 stdout 重定向到被禁读目录下的文件，进程会直接 abort。改为管道输出，由编排器进程写入会话记录。
  5. 用 `nohup … &` 在一次性 shell 调用中启动长任务，编排器会被一起清理，cursor-agent 成为孤儿，写满 64KB 管道后阻塞。改用工具的后台模式运行。
